# ForeverTargetMode
"ForeverTargetMode" affiche un texte clair au milieu de l'écran pendant tes combats : 🟢SINGLE TARGET : tu combats un seul ennemi, utilise ta rotation mono-cible ; 🔴MULTI TARGET (3) : plusieurs ennemis sont sur toi ou ton groupe, passe à ta rotation de zone.  Le texte apparaît quand tu entres en combat et disparaît quand tu en sors.
